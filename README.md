# DIY 2.1 Channel Audio System

A hands-on DIY project where I designed and assembled a
budget-conscious 2.1 channel audio system using repurposed
hardware and commercially available components.

## Objective
Build a functional 2.1 audio system using available/low-cost
components while understanding the power, speaker and amplifier
requirements.

## System Components
- TPA3116D2-based 2.1 channel amplifier
- 10-inch dual-coil subwoofer
- Repurposed stereo speakers
- Additional high-frequency speaker
- ATX PC power supply
- Custom/repurposed speaker enclosure
- Wiring and connectors
